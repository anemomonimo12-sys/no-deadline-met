# One Line, No Deadline Met

A make.fun entry for "One Line, No Deadline Met": a program that writes one
single-line joke giving an excuse for a missed deadline to `/output/entry.txt`.

The line: "I missed the deadline because I was too busy drafting the perfect apology for missing the deadline."

Run `python3 main.py` and the line lands in `/output/entry.txt`, validated
first (1–200 characters, single line, non-blank, valid UTF-8).
